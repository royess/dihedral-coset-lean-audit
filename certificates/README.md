# NAT finite certificates - mixed coverage certificate

**Status:** version 2 retains every four-row-active graph and closes the mixed
edge-incomplete families with uniform row-box and joint JR bounds.  Maps where
a cycle edge is never simultaneously active at both endpoints are not
discarded merely because the other half might supply that edge.

`nat_four_distinct_certificate.mjs` reconstructs the finite combinatorial
ledger used in the four-distinct, `ell_eta = 0` graph-determined branch of
`LEMMA3_HALF_TURN_ERASER.md`.
The global `r_eta` is not fixed to zero: same-row-space/distinct-graph and
cross-row-space pairs use the class-dependent lower bounds replayed by the
joint partition.

Run it with the repository's bundled Node.js runtime:

```text
node certificates/nat_four_distinct_certificate.mjs
```

Pass `--summary` to suppress the generated 48-item JSON list while retaining
all enumeration and digest checks.

The script uses exact rational arithmetic throughout.  It verifies:

- the 369-letter `(s, eta)` alphabet and its published SHA-256;
- all graph spaces generated by bases whose `s`-projections are independent;
- exact alphabet membership in each graph, followed by the four-row and
  four-cycle-edge activity predicates, while separately retaining and
  classifying row-active edge-incomplete maps;
- the original 383 edge-complete coefficient polynomials, plus all 49/597
  row-active polynomials at deficiencies two/one (coefficients are integral
  units of `1/16`);
- all rational cube sections and the exact rank-two equal-positive activity
  cone; and
- the complete 48-item mixed-newborn list and its six mask-pair orbits.

The discrete canonical representation is versioned as
`nat-four-distinct-certificate-v2`.  Subspaces are serialized as rational
RREF rows, lists are sorted lexicographically, polynomial coefficients are
serialized in activity-mask order `0,...,15`, and versioned ledger texts end
with one LF.  The earlier published alphabet digest is the documented
exception: its sorted records have no trailing LF.  A successful run verifies

```text
discreteManifestSha256=ab58303ca18865ef88f2a71f64d21c330aaaa50322ebdf3a2137950b96033e0d
```

It also fixes the rational parameter box, 90-term log interval setting,
uniform allowance, half-envelope bounds, and final outward upper bounds.
For the new edge-omitted families the script recomputes directed `10^40`
fixed-point log intervals for every polynomial.  The resulting half bounds
are `0.249275189385884` and `0.336542401950887`; the exhaustive joint JR
partition remains strictly negative, with worst bound
`-0.004885412605277` (deficiency-two plane with a contained line).
The two additional fixed digests are

```text
outwardBoundsSha256=ce5e8d0a897b14704d601c88d312f83e715a709a45bb3b15fa8b16e3d9200a09
certificateSha256=a5fc261f92047c707e94cb03a102c8b3d6af20f36020a7bbd24b44ef7f70c887
```

The two hashes copied from the originating REPL are retained only as
provenance: its byte-level serialization was not saved, so the script does
not pretend that a differently specified serialization reproduces them.

The classification ledger intentionally distinguishes zero-row, per-half
automatic, signed-repeat, support-repeat, and unclassified maps.  None of the
per-half labels is used as a deletion in the mixed proof: all edge-omitted
polynomials enter the uniform half envelopes and joint partition.
